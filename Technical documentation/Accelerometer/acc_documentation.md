# Описание программы
## Взаимодействие с элементной базой

- **Датчик MPU-6050**: 6-осевой инерциальный измерительный модуль (3-осевой акселерометр + 3-осевой гироскоп). Связь осуществляется по последовательному интерфейсу I²C на скорости 400 кГц (Fast Mode).

- **Интерфейс I²C**: Используется для конфигурации регистров датчика и периодического чтения данных измерений. Микроконтроллер выступает в роли master-устройства, инициирующего все транзакции на шине.

## Входные/выходные параметры системы
### Входные данные

- Сырые показания акселерометра: 16-битные целочисленные значения, считываемые из регистров датчика (0x3B-0x40). Представляют собой мгновенные ускорения по осям X, Y, Z в условных единицах (LSB).

### Выходные данные

- Скорость объекта: значение модуля вектора скорости, рассчитанное путем численного интегрирования калиброванных значений ускорения.

- Диагностическая информация: При использовании отладочного вывода — текущие значения ускорения, накопленная скорость, температура датчика, уровень шума.

## Алгоритм обработки информации
- 1. Фаза инициализации
Инициализация аппаратных интерфейсов: Настройка портов ввода-вывода, конфигурация I²C контроллера на рабочую частоту 400 кГц.
Конфигурация датчика MPU-6050:
    - Выход из спящего режима (сброс бита SLEEP в регистре PWR_MGMT_1)
    - Выбор диапазона измерений акселерометра ±4g через регистр ACCEL_CONFIG
    - Настройка фильтров нижних частот (DLPF) для подавления высокочастотного шума
    - Установка частоты дискретизации (до 1 кГц для акселерометра)
Калибровка акселерометра (опционально, может выполняться при запуске):
    - Измерение смещения нуля при статическом положении датчика
    - Определение масштабных коэффициентов
    - Сохранение калибровочных данных в энергонезависимой памяти
    - Инициализация переменных состояния: Обнуление накопителей скорости, установка начальных значений, подготовка буферов данных.

- 2. Основной цикл измерений
Чтение данных с датчика:
    - Формирование I²C транзакции чтения из регистров акселерометра
    - Получение 6 байт данных (по 2 байта на каждую ось)
    - Проверка целостности данных (контрольные суммы, пределы значений)
Преобразование и калибровка:
    - Преобразование сырых 16-битных значений в физические величины (м/с²)
    - Применение калибровочных коэффициентов

- Численное интегрирование:
Применение метода прямоугольников (простейшая схема Эйлера) для вычисления скорости:
    v_current = v_previous + Δa * Δt

Обновление выходных переменных и подготовка данных для внешних потребителей.
