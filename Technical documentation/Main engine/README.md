# Алгоритм работы драйвера TB6612FNG

![драйвер](L298N_image1.jpg)

### Описание входов 

| Вывод (Multiwatt15) | Название | Функция |
| :---: | :---: | :--- |
| 1; 15 | Sense A; Sense B | Подключение токоизмерительных резисторов для контроля тока нагрузки. |
| 2; 3 | Out 1; Out 2 | Выходы моста A. Подключение нагрузки (например, двигателя A). |
| 4 | Vs | Напряжение питания силовой части. Требуется конденсатор 100нФ между этим выводом и землей. |
| 5; 7 | Input 1; Input 2 | TTL-совместимые входы управления мостом A. |
| 6; 11 | Enable A; Enable B | TTL-совместимые входы разрешения работы мостов A и B. Низкий уровень отключает мост. |
| 8 | GND | Общий (земля). |
| 9 | Vss | Напряжение питания логических схем. Требуется конденсатор 100нФ между этим выводом и землей. |
| 10; 12 | Input 3; Input 4 | TTL-совместимые входы управления мостом B. |
| 13; 14 | Out 3; Out 4 | Выходы моста B. Подключение нагрузки (например, двигателя B). |
| - | N.C. | Не подключено. |


Для корректной работы на вход PWM необходимо подать сигнал периодом в 10 мкс (100 КГц) и коэффициэнтом заполнения 0-100%. При 0% мотор не крутится, при 100 - едет на максимальной скорости.

## Инициализация модуля на МК

### Функции

- **perform_servo_control_step()** - функция шага поворота. Выполняется в основном цикле проекта. Берёт значение скорости из глобальной переменной *SPEED_DESIRED()*, меняет значение CCR для TIM4 раз 50мс. Направление вращения колёс, зависит от того, положительная или отрицательная переменная *SPEED_DESIRED()*. За направление ответственны пины PA5 И PB15.
- **init_motor()** - функция инициации мотора.
