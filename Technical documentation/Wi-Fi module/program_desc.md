# Описание программы в STM32

## Взаимодействие с элементной базой (интерфейс)

Программа взаимодействует со следующими аппаратными компонентами:

- **Wi-Fi модуль EPS8266**: Общается через интерфейс UART для отправки и получения пакетов.

## Входные/выходные параметры

### Входы
- Пакет данных, полученный с Wi-Fi модуля. Содержит преамбулу, скорость, угол.
- Метрики, полученные из других программных модулей.

### Выходы
- Метрики собираются в пакет и отправляются на Wi-Fi модуль.
- Получив пакет данных с углом и скоростью, соответствующие переменные устанавливаются в эти значения.


## Алгоритм обработки информации

1. **Инициализация**:
   - Инициализировать системные периферийные устройства: UART, DMA.
   - Очистить DMA буффер.
   - Запуск DMA на прием данных в буффер.

2. **Основной цикл**:
    - Ожидание прерывания от DMA по окончанию приему данных в буффер. 
    - Остановка работы DMA.
    - Парсинг пришедшего пакета (Преамбула, скорость, угол).
    - Установка значений из пакета в глобальные переменные.
    - Запуск работы DMA.
    - Отправка собранной телеметрии.


# Описание программы в ESP8266

## Взаимодействие с элементной базой (интерфейс)

- **Внешнее устройство** подключенное к точке доступа WiFi модуля.
- **STM32** - взаимодействие через UART

## Входные/выходные параметры

### Входы
- Пакет данных, полученный с Wi-Fi модуля через сокет. Описание пакета - в протоколе связи.
- Метрики, сформированные в пакет, пришедшие от STM32

### Выходы
- Разобранный пакет данных
- Через время установленное в протоколе получаем запрос метрик. В ответном пакете отправляются на внешнее устройство.

## Алгоритм обработки информации

1. **Инициализация**:
- Инициализация Serial для связи с STM32
- Сброс обработчика протокола
- Настройка WiFi точки доступа
- Регистрация WebSocket-сервера на порту 81, путь "/ws"

2. **Основной цикл**:
- Ожидание данных по юарту
- Проверка преамбулы -> запись телеметрии в массив.

3. **Обработчик событий**
- Ожидание ивента сокета - получение данных в бинарном формате
- Разбор полученного пакета
- Отправка ответа на внешнее устройство по протоколу
- Отправка полученных значений угла и скорости (последних) на STM32

3. **Обработка ошибок**:
- Валидация пакета -> проверка на корректный адрес, количество параметров по протоколу, контрольная сумма пакета.
