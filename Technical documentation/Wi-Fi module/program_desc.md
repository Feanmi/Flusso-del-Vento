# Описание программы

## Взаимодействие с элементной базой (интерфейс)

Программа взаимодействует со следующими аппаратными компонентами:

- **Wi-Fi модуль EPS8266**: Общается через интерфейс UART для отправки и получения пакетов, а так же настройки модуля в режиме точки доступа для последующего подключения к ней с других устройств. Для взаимодействия с модулем используются AT команды.

- **UART**: Используется для отправки AT команд и получения пакетов.

## Входные/выходные параметры

### Входы
- HTTP пакет, полученный с внешнего устройства, подключенного к Wi-Fi модулю. Содержит HTTP хэдеры и сообщение, которое описывается протоколом связи в соответсвующем документе.

- Метрики, полученные из других модулей. По запросу от внешнего устройства собираются в ответный пакет и отправляются.

### Выходы
- На каждое сообщение, полученное с внешнего устройства, отправляется ответный пакет, сформированный по протоколу связи.

- Если сообщение содержит команду на установку скорости/угла, то соответствующие переменные устанавливаются в значения которые были получены из пришедшего пакета.


## Алгоритм обработки информации

1. **Инициализация**:
   - Инициализировать системные периферийные устройства: UART, DMA.
   - Настроить Wi-Fi модуль последовательностью AT команд, которые конфигурируют его как точку доступа.
   - Очистить DMA буффер.
   - Запуск DMA на прием данных в буффер.

2. **Основной цикл**:
    - Ожидание прерывания от DMA по окончанию приему данных в буффер. 
    - Остановка работы DMA.
    - Парсинг HTTP пакета на наличие в нем данных и запись их в отдельный буффер.
    - Запуск работы DMA.
    - В случае если оказались в пришедшем пакете, то происходит их парсинг в соответствии с протоколом связи.
    - Создание ответного сообщения, в зависимости от полученной команды из пришедшего сообщения.

3. **Обработка ошибок**:
    - В случае, если пришел неверный HTTP пакет (Пакет должен содержать поле метода которое соответствует "GET", а после через '/' до пробела данные в hex-формате), то он отбрасывается. 
    - В случае если ошибка в самом сообщении, то формируется пакет, сообщающий об ошибках (описаны в протокле связи), который направляется на внешнее управляющее устройство.
