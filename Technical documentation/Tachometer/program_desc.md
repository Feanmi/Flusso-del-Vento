# Описание программы в STM32

## Взаимодействие с элементной базой (интерфейс)

Программа взаимодействует со следующими аппаратными компонентами:

- **Оптический датчик скорости вращения FC-03**: Общается через интерфейс GPIO.

## Выходные параметры

- Скорость движения и частота вращения.

## Алгоритм обработки информации

1. **Инициализация**:
   - Инициализировать системные периферийные устройства: UART, Тimer, GPIO.

Конфигурация таймера (TIM2):

· Настроен в режиме захвата (Input Capture) по каналу 1
· Работает без предделителя, частота таймера = 8 МГц
· Захват происходит по фронту сигнала
· Используется фильтр (значение 15) для подавления дребезга

2. **Основной цикл**:
1. В прерывании HAL_TIM_IC_CaptureCallback:

· Фиксируется время между двумя соседними импульсами
· Вычисляется частота: частота = 8 МГц / (разница_в_тиках)
· Применяется фильтрация:
  · Отбрасываются значения > 400 Гц (максимально допустимая)
  · Отбрасываются значения, отличающиеся более чем в 2 раза от текущего среднего
  · Используется скользящее среднее по 8 последним измерениям

2. Фильтрация и обработка таймаута:

· Если сигнал отсутствует более 500 мс, частота сбрасывается в 0
· Это предотвращает использование устаревших данных

3. Расчет скорости:

· Скорость вычисляется как: скорость = частота × π × диаметр_колеса
· Для диаметра колеса 0.03 м (3 см)

5. Отправка данных по UART:

· Отправляется либо частота , либо скорость
· Используется UART1 на скорости 115200 бод

## Испоьзование программы

Использование программы сводится к вызову следующих функций:
· SPEED_MEASURED_OPT - возвращает значение частоты
· GET_SPEED_MS - возвращает значение скорости (м/с)
· SEND_UART_FREQ - отправляет значение частоты по UART (необходимо для отладки)
· SEND_UART_SPEED - отправляет значение скорости по UART (необходимо для отладки)
