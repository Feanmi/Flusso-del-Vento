
## Общая идея интерфейса

Интерфейс представляет собой **веб-панель удалённого управления и диагностики устройства**. Он работает в браузере (ПК, планшет, смартфон), не требует установки ПО и подходит как для ручного управления, так и для отладки и тестирования.

Основные задачи интерфейса:

- задание команд управления (скорость, угол),
- включение/отключение телеметрии,
- отправка команд на устройство,
- приём и наглядное отображение состояния устройства в реальном времени,
- управление с помощью геймпада.

---

## Блок управления командами (Command packet input)

### Параметры управления

Пользователю доступны три ключевых параметра:

1. **Speed (Скорость)**
    
    - числовое поле ввода (от –127 до +127),
    - ползунок для быстрого изменения значения,
    - чекбокс, позволяющий включать или исключать параметр из команды.
2. **Angle (Угол / направление)**
    - аналогичный набор элементов: число, ползунок, чекбокс,
    - позволяет управлять ориентацией или поворотом устройства.
3. **Telem (Телеметрия)**
    - чекбокс, определяющий, нужно ли запрашивать телеметрические данные в ответе.

---

### Формирование и отправка команды

- В реальном времени отображается **сформированный командный пакет** в шестнадцатеричном виде.
- При некорректной комбинации параметров система сразу сообщает об ошибке («Forbidden combination»).
- Кнопка **Send command packet** отправляет команду на устройство по сети.


---

## Ответ устройства (Response packet)

После отправки команды отображается:

- **сырой ответный пакет** от устройства в hex-формате,
- возможность визуально сверить структуру ответа и корректность обмена.

---

## Отображение телеметрии (Telemetry display)

Телеметрия выводится в виде таблицы с **числовыми значениями и прогресс-барами**, что делает данные легко читаемыми:

Отображаемые параметры:

- **speed** — текущая скорость,
- **pitch / roll** — ориентация устройства,
- **rpm_mag / rpm_opt** — обороты (по разным датчикам),
- **dist** — расстояние,
- **bat_lvl** — уровень заряда батареи.

Особенности:

- данные автоматически масштабируются,
- некорректные или отсутствующие значения помечаются как `INVALID`,
- цветные индикаторы позволяют быстро оценить состояние без анализа чисел.

---

## Управление с геймпада

Интерфейс поддерживает подключение стандартного игрового контроллера:

- **левый стик** — управление скоростью,
- **правый стик** — управление углом,
- автоматическая отправка команд с заданным интервалом,
- удобен для тестов в движении и «живого» управления.

При подключении геймпада интерфейс переходит в режим непрерывного управления без ручного нажатия кнопок.

---

## Адаптация под разные устройства

- На сенсорных устройствах (смартфоны, планшеты) элементы автоматически масштабируются.
- Интерфейс одинаково функционален на ПК и мобильных устройствах
