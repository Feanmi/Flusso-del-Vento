
## Назначение приложения

Веб-приложение предназначено для **удалённого управления устройством** через браузер с помощью **виртуального джойстика** и для **отображения телеметрии** в реальном времени.

---

## Основной функционал

### 1. Управление устройством (джойстик)

На экране отображается **виртуальный аналоговый джойстик**.

Джойстик формирует два управляющих параметра:
- **Speed (скорость)** — по вертикальной оси,
- **Angle (поворот)** — по горизонтальной оси.

Значения нормализуются, имеют «мёртвую зону» и отправляются с заданным периодом.

---

### 2. Настройки джойстика

Доступны два переключателя:

- **Reset joystick input**
    При отпускании джойстика значения возвращаются в ноль.
- **Joystick floats**
     Центр джойстика перемещается в точку первого касания (плавающий джойстик).

---

### 3. Индикация состояния соединения

В верхней части отображается статус **NO CONNECTION** при отсутствии связи.

 Соединение контролируется автоматически:
- при ошибке запроса (таймауте) интервал отправки команд устанавливается в 1 секунду
- если еще 3 запроса вызывают ошибку, соединение считается разорванным
- при восстановлении связи — возвращается к нормальному режиму



---

### 4. Телеметрия 

Приложение отображает данные, получаемые от устройства:

|Параметр|Описание|
|---|---|
|speed|текущая скорость|
|pitch|тангаж|
|roll|крен|
|rpm_mag|обороты магнитного датчика|
|rpm_opt|обороты оптического датчика|
|dist|расстояние|
|bat_lvl|уровень батареи|

Каждый параметр:
- выводится числом,
- сопровождается прогресс-баром,
- помечается как **INVALID**, если флаг валидности не установлен.
